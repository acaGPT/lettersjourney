字母的旅程：从尼罗河到英吉利

The Journey of Letters: From the Nile to England — An Etymological Alphabet Course Grounded in Homer's Greek

基于荷马史诗希腊文底本与英文注释本的英语字母词源启蒙课程大纲。以「画一个东西、读它的名字、再取其首音」为线索， 带学生走完 埃及象形 → 腓尼基 → 希腊 → 拉丁 → 英语 的字母演化链， 并把落脚点放回英文单词本身。

二、课程定位与目标

课程性质英语字母启蒙 + 词源文化课（混龄：高龄段 / 低龄段）
总课时20 课，建议每周 1–2 课，一学期约 10–20 周
适用对象以中文为母语的混龄小组；低龄段重形象与绘画，高龄段重考证与表达
先修要求无；建议低龄段已能认读少量图形

核心目标

  1. 掌握 26 个字母的形状、音值与由来；
  2. 理解字母「埃及象形 → 腓尼基 → 希腊 → 拉丁 → 英语」的演化链；
  3. 通过荷马史诗希腊文亲见「希腊字母阶段」，建立希腊字母与拉丁字母的对应；
  4. 借助英文注释本，认识一批希腊词源的英语词（cognates）；
  5. 产出字母演变海报、象形字母故事书、结业讲解。

教学原则：形象先行、考证随后；高龄段任务重「查」，低龄段任务重「画」；所有词源结论可回溯到公开权威底本。
